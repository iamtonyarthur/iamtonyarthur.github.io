This is the first post on the blog. Replace it with something real — a Markdown file dropped in `_posts/`, named `YYYY-MM-DD-title.md`, is all it takes for a new post to show up here.

A few things worth knowing about how this works:

- Front matter at the top of the file sets the title, date, and tags.
- The first paragraph becomes the excerpt shown on the blog index.
- Tags shown here (like "meta") automatically populate the filter bar above the post list.

## Writing a new post

Create a file in `_posts/`, for example `_posts/2026-10-01-some-topic.md`, with front matter like this one, then write in regular Markdown below the `---`. Push to `main` and GitHub Pages builds it automatically — no extra tooling required.
